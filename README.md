# Cars Dealership – Full Stack Application Development Capstone Project

**Project name:** Best Cars Dealership – Full Stack Web Application

A national car retailer in the U.S. wants a responsive web app where users can view all dealership branches, filter them by state, read the reviews for each dealer, and (after signing up and logging in) post their own reviews.

## Tech stack
- **Frontend:** React, HTML, CSS, Bootstrap
- **Backend:** Django (users, car makes/models with SQLite), Node.js + Express (dealers and reviews with MongoDB)
- **Microservice:** Flask sentiment analyzer deployed on IBM Cloud Code Engine
- **DevOps:** Docker, Kubernetes, GitHub Actions (CI/CD linting)

## Features
- About Us and Contact Us static pages
- User sign-up, login and logout
- List all dealers and filter by state
- Dealer details page with reviews and sentiment icons
- Post a review for a dealer
- Admin site for car makes and car models
